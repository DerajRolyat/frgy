# frgy.app

*just a boy and his frogs*: the landing page for [frgy.app](https://frgy.app).

The page is a single illustrated scene, drawn in SVG, with floating fireflies, frogs that hop and croak, and pond sounds generated in the browser (click **sound on**). There are three versions:

| Page | Scene |
| --- | --- |
| `index.html` | Forest river and ponds at dusk |
| `jungle.html` | Rainforest with a waterfall and tropical frogs |
| `blocks.html` | Minecraft-style blocks |

Each page is a self-contained HTML file with no build step. It is hosted on GitHub Pages and uses `CNAME` for the custom domain.

## Editing

The pages are generated by the Python scripts in `tools/`, which use only the standard library:

```bash
python3 tools/gen_pond.py
python3 tools/gen_jungle.py
python3 tools/gen_blocks.py
```

- `boy.svg`: the boy (pond and jungle versions)
- `water.py`: the river, side channels and ponds
- `jungle_parts.py`: rainforest trees, vines, leaves and the waterfall
- `sound.js`: ambience, croaks and frog animation, shared by all pages
